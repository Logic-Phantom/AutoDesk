# 보안·권한·개인정보

## 권한

- 관리자/root 권한, Windows 서비스, macOS LaunchDaemon, 예약 작업을 사용하지 않는다.
- 감시 대상: 사용자가 직접 추가한 폴더 + (켜 둔 경우) OS 기본 다운로드 폴더. 디스크 전체를 검색하지 않는다.
- 감시 폴더 등록 거부: 드라이브 루트, 시스템 폴더(`C:\Windows`, `C:\Program Files`, `/System`, `/Library`, `/usr` …), AutoDesk 데이터 폴더와 겹치는 위치.
- 프런트엔드 capability는 `core:default` + `dialog:allow-open`(폴더 선택)뿐이다. 클립보드·단축키·자동 실행은 Rust에서만 다루며 웹뷰에서 직접 호출할 수 없다.
- CSP: 외부 스크립트/네트워크 연결을 허용하지 않는다.

## 파일 안전

- 원본 자동 삭제·덮어쓰기 없음. 이동은 `safe_move`(대상이 있으면 거부, 다른 볼륨이면 복사→해시 검증→원본 삭제).
- 이름 충돌은 `name (2).ext`. 모든 이동은 `file_moves`에 기록되어 되돌릴 수 있다.
- 백업 대상 경로는 canonicalize 후 감시 폴더 안인지 다시 확인(symlink 탈출 차단). 앱 데이터 폴더는 항상 제외.
- 스냅샷은 임시 파일에 쓴 뒤 원자적 rename. 복원 전 스냅샷 해시를 검증.
- 실행 파일을 실행하지 않는다. 확장자와 파일 시그니처가 다르면 자동 이동하지 않는다.

## 개인정보

- 클립보드: 단축키를 누른 순간에만 읽는다. 원문/결과는 DB·로그·이력에 저장하지 않고 건수만 기록한다.
- 로그: JSON lines, 1MB 회전(2개 보관). 코드·모듈·짧은 경로만 기록.
- 저장하는 비밀 값 없음(API 키·토큰·비밀번호 없음).
- 외부 전송은 클립보드 정리의 Claude Code 다듬기를 사용자가 동의하고 켠 경우에만 발생. 그 외 네트워크 요청 없음.

## 제거

[UNINSTALL.md](UNINSTALL.md). 삭제 대상은 앱 식별자(`io.github.logicphantom.autodesk`)를 포함한 경로와 앱이 만든 정확한 자동 실행 값/파일 이름뿐이다.

## 업무 모드·도구(v0.3.0)

- 업무 모드는 사용자가 등록한 프로그램·파일·`http(s)` 주소·스크립트만 실행하고, 등록한 프로세스에만 **정상 종료 요청**을 보낸다. 탐색기·시스템 프로세스·AutoDesk는 등록 단계에서 거부한다. 강제 종료는 기본 OFF.
- 퇴근의 PC 종료는 모든 대상이 닫혔을 때만 60초 뒤로 예약하고, 결과 창·`shutdown /a`로 취소할 수 있다.
- 캡처 이미지는 메모리에만 두고 편집 창을 닫으면 지운다. 저장·복사는 사용자가 누를 때만. OCR은 Windows 내장 엔진으로 로컬 처리(외부 전송 없음).
- 파일 저장 명령은 확장자(txt·md·csv·tsv·json·html·png·jpg)를 제한하고, 경로는 OS 대화상자에서 고른 값만 쓴다. 텍스트 읽기는 20MB 이하·바이너리 거부.
- 웹뷰 권한(capability)은 `core:default`, `dialog:allow-open`, `dialog:allow-save`만. CSP는 `img-src 'self' data: blob:`(캡처 미리보기)까지만 허용.
