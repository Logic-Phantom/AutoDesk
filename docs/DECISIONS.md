# 결정 기록

원본 기획(AutoMate Desk Super Prompt)을 그대로 따르되, 혼자 쓰는 무료 개인용 도구라는 조건에 맞춰 아래를 바꾸거나 보완했다.

## 1. 이름·식별자

- 제품명 **AutoDesk**, 실행 파일 `AutoDesk.exe`, 식별자 `io.github.logicphantom.autodesk`.
- 상표: "Autodesk"는 AutoCAD 회사의 등록 상표다. **배포·판매하지 않는 개인용**이라 실사용 문제는 없지만, 나중에 공개 배포할 생각이 생기면 이름을 바꾸는 것이 안전하다. 식별자를 GitHub 계정 기반으로 잡아 다른 앱과 경로·레지스트리 값이 겹치지 않게 했다.

## 2. AI: Gemini 대신 Claude Code CLI (선택, 기본 OFF)

| 항목 | Claude Code CLI (`claude -p`) | Gemini API 무료 등급 |
|---|---|---|
| 비용 | 이미 쓰는 Claude 구독 플랜 안에서 사용(추가 요금 없음) | 무료 등급 있음(한도 작음) |
| 키 관리 | 없음 — 설치된 CLI의 로그인 사용 | API 키를 OS 보안 저장소에 따로 보관해야 함 |
| 데이터 | 구독 약관 적용 | 무료 등급은 Google이 제품 개선에 데이터를 쓸 수 있음 |
| 한도 | 플랜의 사용량 한도(5시간 단위) 공유 | 분당/일일 요청 한도 |
| 구현 | 로컬 프로세스 호출, 네트워크 코드 불필요 | HTTP 클라이언트·키 저장·한도 처리 필요 |

판단: **맞춤법 다듬기 같은 짧은 요청을 단축키로 가끔 보내는 용도라면 Pro 플랜으로도 충분**하다(요청당 수백~수천 토큰, haiku 기본). 그래서 Claude Code CLI를 선택 기능으로 붙였다.

- 정책: Anthropic 공식 CLI를 본인 PC에서 본인 계정으로 실행하는 것이라 허용 범위다. 구독 OAuth 토큰을 꺼내 다른 앱에서 직접 API를 호출하는 방식은 쓰지 않는다(약관상 금지).
- 안전장치: 기본 OFF, 외부 전송 동의 토글을 켜야만 AI 단축키를 켤 수 있음, 단축키를 누른 순간의 텍스트만 전송, 빈 작업 폴더에서 실행(프로젝트 파일 접근 방지), 120초 타임아웃, 결과가 비거나 지나치게 길면 버리고 원문 유지, 원문·결과를 로그/DB에 저장하지 않음.
- 한도를 넘으면 실패로 표시하고 끝난다. 유료 API로 자동 전환하지 않는다.
- Gemini는 구현하지 않았다. 필요해지면 `ai.rs`에 공급자를 하나 더 붙이는 구조다.

## 3. 원본 기획에서 바꾼 점

| 원본 | 변경 | 이유 |
|---|---|---|
| Tokio 비동기 태스크 | 엔진 스레드 1개 + mpsc 채널 | 처리량이 작은 개인용. 순차 처리로 같은 파일 경합이 없고 종료가 단순(스레드 join) |
| 동시 작업 2~3개 설정 | 순차 1개(설정 미노출) | 위와 같음. 노출만 하고 안 쓰는 설정을 만들지 않음 |
| `events`·`action_runs` 테이블 | `jobs` + `activity`로 통합 | 같은 정보를 두 번 저장하지 않음 |
| Tailwind, Zustand | 일반 CSS 토큰 + React 훅 | 의존성 최소화. 상태는 Rust가 소유하므로 프런트 스토어가 필요 없음 |
| Playwright E2E | 미도입 | Tauri 네이티브 창 E2E는 별도 드라이버가 필요. Rust 통합 테스트로 핵심 로직 검증 |
| 빈 줄 3줄 이상 → 2줄 | 기본 최대 1줄(설정 0~5) | 웹 복사 텍스트의 이중 빈 줄 정리가 실제로 더 유용 |
| macOS SMAppService | autostart 플러그인의 LaunchAgent | 플러그인 기본 방식. plist 이름(`AutoDesk.plist`)을 고정해 제거 시 정확히 지움 |
| 별도 uninstaller helper 바이너리 | 일회성 PowerShell/bash 스크립트 | 추가 실행 파일 없이 같은 동작. 스크립트는 실행 후 자기 자신을 삭제 |

## 4. 원본에 없던 보완

- **single-instance**: 두 번 실행해도 프로세스가 하나뿐. 설치 제거 프로그램이 `--quit`로 정상 종료를 요청하는 통로로도 쓴다.
- **창을 코드로 생성**: `--quit`로 실행될 때 WebView를 만들지 않아, 제거 중에 WebView 캐시 폴더가 다시 생기지 않는다.
- **시그니처 불일치 감지**: `.pdf`인데 실제로 실행 파일이면 자동 이동하지 않고 승인을 요청.
- **기존 파일 정리 제안**: 다운로드 폴더에 이미 쌓인 파일은 자동 이동하지 않고 승인 센터에 제안만 올린다.
- **복원 2가지**: 사본으로 복원(덮어쓰지 않음) / 덮어쓰기 복원(현재 상태를 먼저 백업).

## 5. 무료·라이선스·정책 점검

- 앱 코드: MIT. 사용한 의존성은 모두 무료 오픈소스(MIT/Apache-2.0/BSD/ISC/CC0/Zlib) — [LICENSES.md](LICENSES.md).
- 빌드 도구: Rust, Node.js, Visual Studio Build Tools(개인 사용 무료), NSIS(zlib) — 모두 무료.
- GitHub Actions: 공개 저장소는 Windows·macOS 러너 무료.
- 코드 서명: 하지 않는다(인증서·Apple Developer 비용 발생). 결과적으로 Windows SmartScreen "알 수 없는 게시자", macOS Gatekeeper 경고가 뜬다 — 개인용이라 감수. README에 우회 방법 기재.
- 자동 업데이트: 서명 키·서버가 필요해 넣지 않았다(UI에도 표시 안 함).
- 외부 서비스·유료 API·텔레메트리: 없음. 인터넷이 끊겨도 모든 로컬 기능이 동작한다.
